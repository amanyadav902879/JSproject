Concept

Operator Kya Hota Hai? 🤔

Simple bhasha mein: Operator ek special symbol hai jo values pe koi kaam (operation) karta hai. Jaise calculator mein aap 10 + 5 daalte ho — yaha + operator hai, 10 aur 5 operands hain, aur 15 result hai.

Mixer Grinder Analogy

Operator ko mixer grinder samjho. Aap usme ingredients daalte ho (operands), wo apna kaam karta hai (operation), aur result nikal aata hai. Aam + Doodh daala → Mango Shake mila! 🥤

Programming mein: 10 + 5 → + wala mixer dono numbers ko blend karke 15 deta hai. Har operator ka apna alag kaam hai — koi jodta hai, koi compare karta hai, koi decisions ka base banata hai.

// Operator = Kaam karne wala symbol // Operand = Jis pe kaam hota hai // Result = Kaam ke baad jo milta hai let result = 10 + 5; // ↑ ↑ ↑ ↑ // variable operand op operand console.log(result); // 15 ← Result!

JavaScript mein 6 main operator families hain — neeche sab cards check karo, phir har ek ko detail mein todte hain 👇

1. Arithmetic Operators

+ - * / % ** ++ --

Maths ka kaam — jodna, ghataana, guna, bhaag dena. Zomato ka bill calculate yahi se hota hai!

2. Assignment Operators

= += -= *= /= %=

Variable mein value daalna ya update karna. Gullak mein paise jodna = += wala kaam.

3. Comparison Operators

== === != !== > < >= <=

Do cheezon ko compare karna — bada hai, chhota hai, barabar hai? Result hamesha true/false.

4. Logical Operators

&& || !

Decisions ka dimaag — "ye AUR wo dono sahi hain?", "ye YA wo koi ek?". Login logic yahi hai!

5. Ternary Operator

? :

One-line ka if-else! Chhota condition, seedha jawab. Pros ki favourite shortcut.

6. Type Operators

typeof +

Variable ka type pakadna — yaad hai Variable Ka Raja wala Type Detective? Wahi typeof yaha aata hai!

Modulo (%) Ki Real Kahani

Aapke paas 10 toffees hain aur 3 dost. Sabko barabar baanti — har ek ko 3-3 mili, aur 1 toffee bach gayi (aapke liye 😋). Wahi bachi hui toffee hai 10 % 3 = 1!

Modulo ki superpower: even/odd check karna. Koi bhi number 2 se divide karo — remainder 0 aaya toh Even, 1 aaya toh Odd. Yeh ek trick interviewer bhi poochta hai!

// Pizza night ka bill 🍕 let pizzaPrice = 299; let quantity = 3; let totalBill = pizzaPrice * quantity; console.log(totalBill); // 897 // 4 dost mein split karo console.log(totalBill / 4); // 224.25 console.log(totalBill % 4); // 1 ← ₹1 bacha, tension! 😅 // Even/Odd checker console.log(7 % 2); // 1 → Odd console.log(8 % 2); // 0 → Even // Game mein power-up 💪 console.log(2 ** 10); // 1024 (double-double karte gaye) // Counter let kills = 5; kills++; console.log(kills); // 6
BOMB ALERT: + Operator Ka Double Role!

JavaScript mein + ka ek secret identity hai — numbers ke saath ye jodta hai, lekin string ke saath chipkata (concatenate) hai! Yeh interview ka favourite trap hai:

  • 5 + 3 → 8 ✅ (dono number, normal addition)
  • "5" + 3 → "53" 😱 (string mili toh JS ne chipka diya!)
  • "5" - 3 → 2 🤯 (minus ka koi chipkane wala kaam nahi, toh JS ne "5" ko number bana diya!)
  • 10 / 0 → Infinity (zero se divide? JS bolta hai "infinite bhai!")
++i vs i++ — Pehle Badhao Ya Pehle Use Karo?

i++ (post-increment): pehle current value use karo, phir badhao. ++i (pre-increment): pehle badhao, phir use karo. Interview mein yeh bhi poochte hain!

== vs === : Pehchaan Ki Problem

== ek chill aadmi hai — dekhta hai value same hai kya, bas. "5" (string) aur 5 (number)? "Areyy value toh same hai, pass karo!" ✅

=== ek strict security guard hai — pehle value check karta hai, phir type bhi. "5" string hai aur 5 number? "Type hi alag hai bhai, ENTRY BAND!" ❌

Rule yaad rakho: 99% baar === hi use karo. Interview mein bhi yahi expected hai!

Logical Operators — Dimaag Wale Operators 🧠

Jab ek se zyada conditions ko jodna ho, tab yeh operators kaam aate hain. Real life mein bhi roz use karte ho — "agar aur terrace pe hai toh milte hain", "ya toh call kar ya message".

Bank Locker Analogy (&&)

Bank locker ke do taale hote hain — ek key aapki, ek bank ki. DONO keys sahi hon tabhi locker khulta hai. Ek bhi galat? Locker band! Yahi hai && ka strict rule: dono true → tabhi true.

🚕 OR (||) — Backup Plan
  • Ola mili → chalo (true)
  • Uber mili → chalo (true)
  • Dono mil gayi → pehli wali se chalo! (true)
  • Dono nahi mili → paidal jao (false)
  • Rule: koi EK bhi true → result true
💡 NOT (!) — Ulta Scanner
  • !true → false
  • !false → true
  • isDarkMode = !isDarkMode → dark/light mode toggle!
  • Light switch: ON ka ulta OFF
  • Rule: jo hai uska ulta

// Instagram login logic 📸 let usernameSahi = true; let passwordSahi = false; console.log(usernameSahi && passwordSahi); // false → login FAIL! console.log(usernameSahi || passwordSahi); // true → (par dono chahiye hote hain 😄) // Movie ticket: age AUR ticket dono chahiye 🎬 let age = 20; let hasTicket = true; console.log(age >= 18 && hasTicket); // true → andar jao! // Dark mode toggle 💡 let isDarkMode = false; isDarkMode = !isDarkMode; console.log(isDarkMode); // true → andhera ho gaya!
Short-Circuit Evaluation — Smart Shortcut

&& pehli value false milti hai toh dusri check hi nahi karta (answer toh false hi hoga na — time waste kyu kare?). || pehli true milti hai toh seedha return kar deta hai. Isi ka use karke pros fallback/default values banate hain:

let username = savedName || "Guest"; — savedName hai toh wahi, nahi toh "Guest"! 🎯

Family #5

Ternary Operator — One-Line Ka If-Else ⚡

Ternary ek shortcut hai: chhota condition lo, ek line mein decision lo. Formation: condition ? haanWalaJawab : nahiWalaJawab. Poora if-else block sirf ek line mein!

Chai Ya Coffee Analogy ☕

Mummy poochti hain: "Subah hai? Toh chai, warna coffee." — bas yahi ternary hai!
subahHai ? "Chai ☕" : "Coffee ☕"

? ke baad wala jawab tab milta hai jab condition true ho, : ke baad wala tab jab false ho. Simple!

🐢 Lamba Tarika (if-else)
let age = 20; let status; if (age >= 18) { status = "Adult"; } else { status = "Minor"; } // 6 lines gaye!
🐇 Ternary Tarika (1 line!)
let age = 20; let status = age >= 18 ? "Adult" : "Minor"; // BOOM! 1 line 🎯
// GPay payment check 💸 let balance = 450; let bill = 300; console.log(balance >= bill ? "Payment Done ✅" : "Insufficient Balance ❌"); // "Payment Done ✅" // Zomato free delivery 🍔 let cartTotal = 850; console.log(cartTotal >= 999 ? "FREE Delivery 🎉" : "₹40 Delivery Fee"); // "₹40 Delivery Fee" // Chained ternary — Grade machine (advanced!) let marks = 82; let grade = marks >= 90 ? "A+" : marks >= 75 ? "B" : marks >= 60 ? "C" : "Padhai karo bhai 📚"; console.log(grade); // "B"
Kab Ternary, Kab If-Else?

Ternary: jab sirf value choose karni ho (2 options). If-else: jab multiple kaam karne ho ya 3+ complex conditions hon. Chained ternary 3 se zyada lamba ho gaya toh code padhna mushkil — tab if-else better hai. Balance rakho!

🔴 Hard Task 5: Variable Swap (No Third Person!)

a = 5 aur b = 10 hai. Dono ki values swap karni hain (a = 10, b = 5). Challenge: teesra variable use karna mana hai! Sirf + aur - operators se karo. (Interview mein poochha jata hai!)

Idea: Maths trick! Dono ko jodo → total. Phir total se b ghatao toh a milta hai, aur total se a ghatao toh b milta hai. 3 steps: a = a + b, phir b = a - b, phir a = a - b

console.log("b =", b); // b = 5

          : marks >= 75 ? "B 👍"
          : marks >= 60 ? "C 😊"
          : "Padhai karo bhai! 📚";

console.log(`Marks: ${marks}`);
console.log(`Grade: ${grade}`);
// Grade: B 👍

== vs === Rules

  • == type badal ke bhi compare karta hai
  • === value + type dono check karta hai
  • 99% baar === use karo
  • 5 == "5" → true (trap!)
  • 5 === "5" → false (safe)
  • null == undefined → true
  • NaN === NaN → false (weird!)

Yaad Rakhne Wali Baatein

  • Comparison result hamesha boolean (true/false)
  • &&: dono true tabhi true
  • ||: koi ek true toh true
  • !: ulta kar deta hai
  • Short-circuit: && false milte hi rukta hai, || true milte hi
  • Fallback pattern: x = val || "default"
  • Even/odd: num % 2 === 0
  • Precedence: * pehle, + baad (BODMAS)
