Topic 01

DOM Kya Hai?

DOM = Document Object Model. HTML page ka ek tree-like structure jo JavaScript se access hota hai. Har tag ek "node" hai — head, body, div, p, h1 sab nodes hain.

html
// DOM tree concept: // document (root) // └── html // ├── head // │ ├── title // │ └── script // └── body // ├── h1 // ├── p // └── div // ├── ul // │ └── li // └── button // JavaScript se DOM access karo aur modify karo console.log(document); // #document — root node console.log(document.body); // <body> element console.log(document.head); // <head> element console.log(document.title); // Page ka title text console.log(document.URL); // Current page URL
Soch kaise: HTML = Structure (skeleton), CSS = Style (makeup), JS/DOM = Behavior (brain + hands). DOM se JS HTML ko read, modify, create, delete kar sakta hai.
Topic 02

Select Elements — 3 Tarike

javascript
// 1. getElementById — FAST, ek element (id se) const h1 = document.getElementById("main-title"); console.log(h1.textContent); // 2. querySelector — FIRST match (CSS selector) const firstBtn = document.querySelector(".p-btn-primary"); const byTag = document.querySelector("h1"); const byId2 = document.querySelector("#main-title"); // 3. querySelectorAll — ALL matches (NodeList) const allBtns = document.querySelectorAll("button"); const allP = document.querySelectorAll("p"); console.log("Buttons:", allBtns.length); console.log("Paragraphs:", allP.length); // NodeList vs Array — IMPORTANT! const divs = document.querySelectorAll("div"); // divs.forEach(d => ...) // ✅ Works (NodeList has forEach) // divs.map(...) // ❌ Error! (not a real array) const divArray = [...divs]; // ✅ Convert to array first divArray.map(d => console.log(d.className)); // Nested selectors const item = document.querySelector("ul li:first-child"); const active = document.querySelector(".nav-link.active"); const inside = document.querySelector(".card .btn");
querySelectorAll returns NodeList, not Array! forEach chalega par map/filter/reduce nahi. Pehle [...nodeList] karke array banao.
Topic 03

Content Change — textContent vs innerHTML

javascript
// textContent — SAFE (text only, no HTML parsing) const h1 = document.querySelector("h1"); h1.textContent = "New Title"; h1.textContent = "<strong>Bold?</strong>"; // Shows as plain text! // innerHTML — UNSAFE but powerful (parses HTML) h1.innerHTML = "<em>Italic Title</em>"; // Shows as italic! // ⚠️ innerHTML security risk — user input kabhi innerHTML mat daalo! // XSS attack ho sakta hai const userInput = "<script>alert('hacked!')</script>"; // element.innerHTML = userInput; // DANGER! // Value — form inputs ke liye const input = document.querySelector("input"); console.log(input.value); // Current value input.value = "New Value"; // Set value // Get/set attributes const img = document.querySelector("img"); console.log(img.getAttribute("src")); // Get attribute img.setAttribute("alt", "Description"); // Set attribute img.removeAttribute("title"); // Remove // Style manipulation h1.style.color = "red"; h1.style.fontSize = "3rem"; h1.style.padding = "20px"; h1.style.background = "#1a1a2e"; h1.style.borderRadius = "12px"; // style property name = CSS mein kebab-case, JS mein camelCase // CSS: font-size → JS: fontSize // CSS: background-color → JS: backgroundColor // CSS: border-radius → JS: borderRadius // classList — best way to manage classes h1.classList.add("active"); // Add class h1.classList.remove("active"); // Remove class h1.classList.toggle("active"); // Add if not there, remove if there h1.classList.contains("active"); // Check exists → true/false h1.classList.replace("old", "new"); // Replace class
textContent vs innerHTML: Hamesha textContent use karo text change ke liye. innerHTML sirf trusted content ke liye — user input kabhi mat daalo (XSS risk).
Topic 04

classList — Class Management

javascript
const btn = document.querySelector("button"); // Add class btn.classList.add("active"); // <button class="active"> btn.classList.add("btn-primary"); // <button class="active btn-primary"> // Remove class btn.classList.remove("active"); // <button class="btn-primary"> // Toggle — add if missing, remove if present btn.classList.toggle("active"); // click karne par on/off // Check class exists btn.classList.contains("active"); // true/false // Replace — swap class btn.classList.replace("old-class", "new-class"); // Multiple classes btn.className = "btn btn-primary active"; // Overwrites ALL classes (avoid!) // classList vs className: // classList → Add/remove individual classes (safe) // className → Replace ALL classes at once (destructive)
Topic 05

Create & Remove Elements Dynamically

javascript
// Create element const div = document.createElement("div"); div.textContent = "Dynamically created!"; div.className = "ic ab"; document.body.appendChild(div); // Create with HTML const card = document.createElement("div"); card.innerHTML = `<h3>Title</h3><p>Content here</p>`; document.querySelector(".cw").prepend(card); // Add at start // append() — end mein, prepend() — start mein // before() — pehle, after() — baad mein (reference element ke relative) // Remove element const old = document.querySelector(".ic"); old.remove(); // Gone forever! // Remove children const list = document.querySelector("ul"); while (list.firstChild) list.removeChild(list.firstChild); // Clear list // Clone an element const original = document.querySelector(".proj"); const clone = original.cloneNode(true); // deep clone (with children) const shallow = original.cloneNode(false); // shallow (no children) document.body.appendChild(clone); // Move element (no copy — actually moves) const h1 = document.querySelector("h1"); document.querySelector(".cw").prepend(h1); // Move h1 to start of .cw // Replace element const newEl = document.createElement("h2"); newEl.textContent = "Replaced!"; document.querySelector("h1").replaceWith(newEl); // innerHTML se bhi create kar sakte ho (quick but unsafe) container.innerHTML += `<div class="ic bl">New item ${i}</div>`;
Topic 06

Event Listeners

javascript
// Basic syntax button.addEventListener("click", (event) => { console.log("Clicked!", event.target); }); // Common events input.addEventListener("input", (e) => { console.log("Typed:", e.target.value); }); input.addEventListener("keydown", (e) => { if (e.key === "Enter") console.log("Enter pressed"); }); form.addEventListener("submit", (e) => { e.preventDefault(); // Stop page reload! console.log("Form submitted"); }); // Mouse events el.addEventListener("mouseover", () => { /* hover in */ }); el.addEventListener("mouseout", () => { /* hover out */ }); el.addEventListener("mousemove", (e) => { /* track position */ }); // Remove listener — need function reference! function handleClick() { console.log("Clicked!"); } btn.addEventListener("click", handleClick); btn.removeEventListener("click", handleClick); // Add once — auto-remove after first fire btn.addEventListener("click", () => { console.log("One time only!"); }, { once: true }); // Multiple events same element const log = document.querySelector(".po"); log.addEventListener("click", () => log.style.color = "var(--ac)"); log.addEventListener("dblclick", () => log.style.color = "var(--rd)"); // Event on dynamically created elements const btn = document.createElement("button"); btn.textContent = "Dynamic Button"; btn.addEventListener("click", () => alert("I'm dynamic!")); document.body.appendChild(btn); // Event delegation — PARENT pe listener lagao document.addEventListener("click", (e) => { if (e.target.matches(".todo-del")) { e.target.closest(".todo-item").remove(); } });
{ once: true } use karo jab event sirf ek baar chalana ho — auto remove ho jaata hai. RemoveEventListener ke liye function reference chahiye.
Topic 07

Event Bubbling & Delegation

javascript
// BUBBLING — child se parent ke taraf event travel karta hai // <div id="outer"> // <div id="inner"> // <button>Click</button> // </div> // </div> // Click on button → event bubbles: button → inner → outer → body → html → document document.getElementById("outer").addEventListener("click", (e) => { console.log("Outer clicked!", e.target, e.currentTarget); // e.target — jispe actually click hua (button) // e.currentTarget — jispe listener lagaya (outer) }); // stopPropagation — bubbling rok do document.getElementById("inner").addEventListener("click", (e) => { e.stopPropagation(); // outer ka listener nahi chalega console.log("Inner clicked!"); }); // DELEGATION — parent pe ek listener, children ke liye kaam karo // Best practice for dynamic elements! <ul id="list"> <li data-id="1">Item 1</li> <li data-id="2">Item 2</li> <li data-id="3">Item 3</li> </ul> // ONE listener for ALL li — even new ones! document.getElementById("list").addEventListener("click", (e) => { const li = e.target.closest("li"); if (!li) return; const id = li.dataset.id; console.log(`Clicked item ${id}`, li.textContent); li.classList.toggle("done"); }); // Benefits of delegation: // 1. Ek listener for 100 elements (performance!) // 2. Dynamically added elements automatically work // 3. Memory efficient // 4. Easier to manage
Rule: Hamesha delegation use karo jab multiple similar elements ho. e.target.closest('.class') se exact element dhundho. Performance aur maintainability dono better hoti hai.
Topic 08

Event Object — e ke andar sab kuch hai

javascript
document.addEventListener("click", (e) => { console.log(e.type); // "click" console.log(e.target); // Element jispe click hua console.log(e.currentTarget); // Element jispe listener hai console.log(e.clientX, e.clientY); // Mouse position (px from viewport) console.log(e.pageX, e.pageY); // Mouse position (px from document) console.log(e.key); // Key name ("Enter", "Escape") console.log(e.code); // Key code ("Enter", "Escape") console.log(e.ctrlKey); // Is Ctrl pressed? console.log(e.shiftKey); // Is Shift pressed? console.log(e.preventDefault); // Call to stop default behavior }); // Keyboard events document.addEventListener("keydown", (e) => { if (e.key === "Escape") console.log("Escape pressed"); if (e.ctrlKey && e.key === "s") { e.preventDefault(); // Block Ctrl+S save console.log("Ctrl+S blocked!"); } }); // Input events input.addEventListener("input", (e) => { console.log("Value:", e.target.value); console.log("Input type:", e.inputType); // "text", "number", etc. }); // Form submit form.addEventListener("submit", (e) => { e.preventDefault(); // Page reload rok do! const formData = new FormData(e.target); console.log(Object.fromEntries(formData)); }); // Mouse events div.addEventListener("mousemove", (e) => { div.style.left = e.clientX + "px"; div.style.top = e.clientY + "px"; }); // Touch events (mobile) el.addEventListener("touchstart", (e) => { const touch = e.touches[0]; console.log("Touch at:", touch.clientX, touch.clientY); }); // change event (fires when input loses focus after change) select.addEventListener("change", (e) => { console.log("Changed to:", e.target.value); });
