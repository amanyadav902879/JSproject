Concept

Loop Kya Hota Hai? 🤔

Loop ka matlab hai repeat karna. Socho: teacher bolti hai "I love JS" 100 baar likho. Ek-ek line likhoge? 😩 Nahi! Ek loop likho — 3 lines ka code 100 baar ka kaam karega. Ek baar likho, hazaar baar chalao — yahi hai programming ka asli superpower!

Gym Reps Analogy

Trainer bolta hai: "10 push-ups karo." Tum kya karte ho? Rep 1 karo → count karo → 10 hua? Nahi → phir karo → count karo → ... jab tak 10 na ho jaye. Ye EXACTLY wahi hai jo loop karta hai!

Programming mein: for (let rep = 1; rep <= 10; rep++) — rep 1 se shuru, har baar count badhao, 10 tak repeat. Pichle chapter ki conditions (Chapter 3) yahi pe kaam aati hai — loop har round mein check karta hai: "abhi rukna hai ya aage ghoomna hai?" 🔄

// Loop ka life cycle (yeh 3 cheezein har loop mein hoti hai): // 1. INIT → counting variable banao (ek baar) // 2. CHECK → condition true? toh chalao (har round mein) // 3. UPDATE → count badhao (har round ke baad) for (let i = 1; i <= 5; i++) { console.log("Round", i); // 5 baar chalega } // Round 1, Round 2, Round 3, Round 4, Round 5

JavaScript mein 6 looping tools hain — har ek ka apna moment. Sab cards dekho, phir ek-ek karke detail mein 👇

1. for loop

for (init; check; update) { ... }

Sabse popular — jab ginti pata hai (10 baar, 100 tak). Tino parts ek line mein — tight aur clean!

2. while loop

while (condition) { ... }

Jab ginti nahi pata, sirf condition pata hai — "jab tak pet na bhare khaao". Pehle check, phir chalao.

3. do-while loop

do { ... } while (condition);

Pehle chalao, phir check karo — kam se kam 1 baar pakka chalega! Menu dikhana, retry lena.

4. break & continue

break; / continue;

break = loop se bahar nikalo. continue = ye round skip karo, agla chalao. Loop ka remote control!

5. for...of

for (let item of list) { ... }

Array ya string ke har item pe ek-ek baar — bina counting ke! Fruits list, playlist, messages.

6. for...in & Nested

for (let key in obj) / loop in loop

for...in object ki keys pe chalta hai. Nested loop = loop ke andar loop — patterns banane ke liye!

Tool #1

for Loop — Repeat Ka Raja 👑

Jab tumhe pata hai kitni baar chalana hai — 10 push-ups, 5 stars, 1 se 100 tak — tab for loop. Bracket ke andar 3 parts hote hai, semicolon se alag: shuru; check; badhao. Ek line mein poora plan!

// Syntax: for (START; CHECK; UPDATE) for (let i = 1; i <= 5; i++) { // ↑ ↑ ↑ // init check update console.log("Rep no.", i); } // Rep no. 1 ... Rep no. 5 // "I love JS" 3 baar — dekho kitna short! 🔥 for (let i = 0; i < 3; i++) { console.log("I love JS ❤️"); } // Ulta ginti — 5 se 1 tak for (let i = 5; i >= 1; i--) { console.log(i); } // 5 4 3 2 1
for Loop Ke 3 Rules

1. init sirf PEHLI baar chalta hai, check + update har round mein.
2. i++ (update) likhna kabhi mat bhoolna — bhool gaye toh i wahi rahega, condition hamesha true, loop kabhi nahi rukega = INFINITE LOOP! 😱
3. i <= 5 matlab 1,2,3,4,5 (5 baar). i < 5 matlab 1,2,3,4 (4 baar, agar i=1 se shuru). Off-by-one ka dhyan rakho!

Tool #2

while Loop — Jab Tak Chalega ♾️

Kabhi socha hai — "jab tak pet na bhare, khaate raho"? Ginti nahi pata kitni rotiyan lagengi, bas condition pata hai: "pet bhara? RUKO, warna aur khao." Yahi while loop hai — condition pe depend karta hai, counting pe nahi!

// Syntax: pehle CHECK, phir chalao while (condition) { // kaam karo // update — BHOOLNA MAT! 😅 } // Pet bhara check 🍛 let roti = 0; let petBhara = false; while (petBhara === false) { roti++; console.log("Roti #" + roti + " khaayi 🍽️"); if (roti >= 4) petBhara = true; } console.log("Pet bhara! Ab sona 😴"); // Paise double karo jab tak 100 na ho let paisa = 1; while (paisa < 100) { paisa = paisa * 2; console.log("Ab hai ₹" + paisa); } // ₹2, ₹4, ₹8, ₹16, ₹32, ₹64, ₹128
BOMB ALERT: Infinite Loop — Browser Hang! 💀

while loop mein update likhna bhool gaye toh condition kabhi false hi nahi hogi — loop kabhi nahi rukega:

  • let i = 1; while (i <= 5) { console.log(i); } — i++ gaya! i hamesha 1 rahega → page hang, laptop garam, battery khatam! 🔥
  • Fix: loop ke andar hamesha update karo: i++ ya condition ko badalne wala kuch
  • Emergency exit: break lagao ya condition aisi banao jo kabhi na kabhi false ho
for ya while? Kab Kya?

for: ginti pata hai — "10 baar", "1 se 100", "array ke saare items". Counting wala kaam.
while: ginti nahi pata — "jab tak user sahi input na de", "jab tak game khatam na ho", "jab tak balance khatam na ho". Condition wala kaam.
Dono se ek dusre ka kaam ho sakta hai — par sahi choice = clean code!

Tool #3

do-while — Pehle Karo, Phir Socho 🎲

JEE form bharte waqt portal pehle form dikhata hai, phir check karta hai ki bharne layak ho ya nahi. Menu pehle dikhaya jata hai, phir poocha jata hai "order karega?" — at least EK baar toh hona hi hai! Yahi do-while hai: pehle kaam, baad mein check.

// Syntax: do PEHLE, check BAAD mein (semicolon yaad!) do { // ye code KAM SE KAM 1 BAAR pakka chalega } while (condition); // ← ye semicolon zaroori hai! // ATM PIN — pehle poochho, galat toh dobara 🏧 let tries = 0; let pinSahi = false; do { tries++; console.log("Attempt #" + tries + ": PIN poocha"); if (tries >= 3) pinSahi = true; } while (pinSahi === false && tries < 3); // MAGIC DEMO: condition pehle se false, PHIR BHI chala! 🤯 let x = 100; do { console.log("Chal gaya! x =" + x); x++; } while (x < 5); // "Chal gaya! x =100" — 1 baar chala, chahe 100 < 5 false hai!

Tool #4

break & continue — Loop Ka Remote 🎛️

Movie dekh rahe ho, boring ho gaya? Beech mein hi chhod ke bahar — yeh break hai. Thali mein karela aaya? Wo skip karo, baaki sab khao — yeh continue hai. Dono loop ke andar conditions ke saath use hote hai!

break — Loop Se BAHAR
  • Loop turant khatam — uske baad ka code chalta hai
  • Jaise: list mein item mil gaya — aur dhundhne ki zaroorat nahi!
  • Switch chapter se yaad hai? Wahi bhi break se nikalta tha!
continue — Sirf Ye Round SKIP
  • Current round skip, loop chalta rehta hai
  • Jaise: even numbers chhod do, sirf odd print karo
  • break ki tarah loop ko nahi maarta — bas jhatka deta hai!
// break: 7 pe STOP 🛑 for (let i = 1; i <= 10; i++) { if (i === 7) { console.log("7 mil gaya — dhundhna band! 🔍"); break; } console.log(i); } // 1 2 3 4 5 6, phir "7 mil gaya" — 8,9,10 kabhi nahi chale // continue: even numbers SKIP 🫥 for (let i = 1; i <= 6; i++) { if (i % 2 === 0) continue; // even? skip karo console.log("Odd number:", i); } // Odd number: 1, 3, 5
BOMB ALERT: continue + while = Dhyan Se!

while loop mein continue ke baad agar update wali line pehle nahi hai, toh update kabhi nahi hoga — infinite loop! 😱
while (i < 5) { if (i === 3) continue; console.log(i); i++; } — i = 3 pe continue hua, i++ kabhi nahi chala, i hamesha 3 = hang! Fix: update continue se pehle rakho, ya for loop use karo (waha update har round chalta hi hai).

Tool #5

for...of & for...in — Seedha Item Lo 🎁

Array ke har item ke liye i = 0; i < arr.length; i++ likhna boring hai na? for...of bolta hai: "bhai counting mujhe karne do, tum bas item lo!" Aur for...in object ki keys ke liye hai. Dono life savers hai!

// for...of — ARRAY ke items (values milte hai) let fruits = ["aam", "seb", "kela"]; for (let fruit of fruits) { console.log("Aaj khao:", fruit); } // Aaj khao: aam / seb / kela // for...in — OBJECT ki keys let student = { naam: "Rahul", marks: 92, city: "Delhi" }; for (let key in student) { console.log(key, "→", student[key]); } // naam → Rahul / marks → 92 / city → Delhi // String pe bhi for...of chalta hai! let naam = "JS"; for (let letter of naam) console.log(letter); // J / S
BOMB ALERT: of ya in? Confuse Mat Hona!
  • for...of → VALUES deta hai (aam, seb, kela) — arrays, strings pe use karo
  • for...in → KEYS/INDEX deta hai (0, 1, 2 ya "naam", "marks") — objects ke liye bana hai
  • Array pe for...in chala diya toh items nahi, indexes milenge — 0, 1, 2! 🤦
  • Common mistake: for (let fruit in fruits) → fruit = 0, 1, 2 (numbers!), aam nahi
Yaad Rakhne Ka Tareeka

"of" = object ki value... matlab item — array ke of items ek-ek karke milte hai. "in" = index/keys — object ke in keys milte hai. Arrays → of, Objects → in. Bas!

Tool #6

Nested Loops — Loop Ke Andar Loop 🔁🔁

Ghari dekho — ghanta wala needle 1 ghanta poora karta hai, aur us dauraan minute wala needle 60 baar ghoomta hai! Ek ke andar ek — yahi nested loop hai. Outer loop 1 baar chale, inner loop poora chalega. Patterns, tables, grids — sab isi se bante hai!

// Nested loop: 3 rounds × 4 reps = 12 baar! for (let round = 1; round <= 3; round++) { console.log("--- Round" + round + " ---"); for (let rep = 1; rep <= 4; rep++) { console.log(" Rep" + rep); } } // Star pattern — pehli baar dekhoge toh dimaag ghoomta hai 😵 for (let i = 1; i <= 3; i++) { let line = ""; for (let j = 1; j <= i; j++) { line = line + "⭐"; } console.log(line); } // ⭐ / ⭐⭐ / ⭐⭐⭐
Nested Ka Rule + Performance Baat

Rule: Outer loop ki har 1 iteration mein inner loop apni poori life jiye ga. 3×4 = 12 baar, 100×100 = 10,000 baar! Isliye nested loops ko O(n²) kehte hai interview mein — data bada hua toh iterations square ho jaate hai. Chhota data fine, lakhon rows pe soch samajh ke likhna!

6 Workshop Tasks 💪

Pehle khud likho, phir hint dekho, phir solution match karo. Yaad hai na — dekhne se 20%, karne se 100% seekhte hai! 🔥

🟢 Easy Task 1: 1 se 20 Tak Ginti (for se)

for loop se 1 se 20 tak numbers print karo — har number ek line mein. Fir wahi kaam i -= 1 se ulta karo: 20 se 1 tak!

Idea: for (let i = 1; i <= 20; i++). Ulta karne ke liye: let i = 20; i >= 1; i-- — check ulta, update bhi ulta!
for (let i = 1; i <= 20; i++) {
  console.log(i);
}
// 1 2 3 ... 20

for (let i = 20; i >= 1; i--) {
  console.log(i);
}
// 20 19 18 ... 1
🟢 Easy Task 2: 7 Ka Table

7 ka table print karo is format mein: 7 x 1 = 7, 7 x 2 = 14 ... 7 x 10 = 70. String aur number ko + se jodna yaad hai na (Chapter 1)!

Idea: n = 7 variable lo. Loop i ko 1 se 10 tak ghumaao aur print karo: n + " x " + i + " = " + (n * i). Brackets lagao multiplication ke liye!
let n = 7;

for (let i = 1; i <= 10; i++) {
  console.log(n + " x " + i + " = " + (n * i));
}
// 7 x 1 = 7
// 7 x 2 = 14
// ...
// 7 x 10 = 70
🟡 Medium Task 3: Sirf EVEN Numbers (2 Tarike!)

1 se 30 tak ke sirf even numbers print karo — par do alag tarike se: (1) step wala trick i += 2, (2) if + continue wala tariqa. Dono ka output same aana chahiye!

Idea: Tarike 1: 2 se shuru karo, step 2 — for (let i = 2; i <= 30; i += 2). Tarike 2: i % 2 !== 0 pe continue karo (odd skip).
// Tarike 1: step trick
for (let i = 2; i <= 30; i += 2) {
  console.log(i);
}

// Tarike 2: continue se odd skip
for (let i = 1; i <= 30; i++) {
  if (i % 2 !== 0) continue;
  console.log(i);
}
// Dono ka output: 2 4 6 ... 30
🟡 Medium Task 4: 1 se 50 Tak Ka Jod (Sum)

total naam ka variable bahar banao (0 se shuru). Loop ke andar har number ko total mein jodo. End mein print karo: "Sum: 1275" hona chahiye. Ye accumulator pattern hai — Zomato cart isi se banta hai!

Idea: total ko loop ke BAHAR banao (andar banaoge toh har round reset ho jayega!). Andar: total = total + i ya short mein total += i.
let total = 0;   // BAHAR — accumulator!

for (let i = 1; i <= 50; i++) {
  total += i;    // har round jodte jao
}

console.log("Sum:", total);
// Sum: 1275
🔴 Hard Task 5: Number Ulta Karo (1234 → 4321)

num = 1234 ko ulta karo — 4321! Loop chale jab tak number 0 na ho jaye. Trick: num % 10 se aakhri digit milti hai, Math.floor(num / 10) se aakhri digit udd jaati hai. Chapter 2 ka modulo yaha kaam aayega!

Idea: Ek rev = 0 banao. Har round: rev = rev * 10 + (num % 10) — digit uthao, rev mein peeche jodo. Fir num = Math.floor(num / 10). while loop use karo: while (num > 0).
let num = 1234;
let rev = 0;

while (num > 0) {
  let digit = num % 10;          // 4, 3, 2, 1
  rev = rev * 10 + digit;        // 4, 43, 432, 4321
  num = Math.floor(num / 10);    // 123, 12, 1, 0
}

console.log("Ulta:", rev);
// Ulta: 4321
🔴 Hard Task 6: Factorial (5! = 120)

Factorial matlab: 5! = 5 × 4 × 3 × 2 × 1 = 120. Loop se calculate karo n = 5 ke liye. Bonus: 0! = 1 bhi handle karna hai (kaifiyat: multiplication 1 se shuru hota hai, 0 se nahi!).

Idea: Sum ki tarah hi hai — bas jodne ki jagah guna karna hai. Accumulator fact = 1 lo (0 nahi! 0 se guna karoge toh sab 0 ho jayega 😅). Loop: fact *= i.
let n = 5;
let fact = 1;   // 1 se shuru — 0 se NAHI!

for (let i = 1; i <= n; i++) {
  fact = fact * i;
}

console.log(n + "! =", fact);
// 5! = 120

// n = 0 test karo → 0! = 1 (loop nahi chalega,
// fact = 1 hi print hoga — automatic sahi!)

Digit Reverser + Palindrome

Number ko ulta karo (while + modulo), phir check karo palindrome hai ya nahi — mummy yaad karvao momos ki tarah same-ulte!

while%===
let num = 12321;
let original = num;
let rev = 0;

while (num > 0) {
  rev = rev * 10 + (num % 10);
  num = Math.floor(num / 10);
}

console.log("Ulta:", rev);
if (rev === original) {
  console.log("Palindrome hai! 🪞");
} else {
  console.log("Palindrome nahi 😢");
}

Challenges: 1) Digit sum bhi nikalo (12321 → 9). 2) String wala tarike se bhi karo (split-reverse-join) — compare karo. 3) 100-200 ke saare palindromes dhundo (nested loop + logic)!

Kaunsa Loop Kab?

  • for — ginti pata hai (n baar, 1 se 100)
  • while — condition pata hai, ginti nahi
  • do-while — kam se kam 1 baar pakka (menu, retry)
  • for...of — array/string ke items
  • for...in — object ki keys
  • nested — grid, table, patterns

Common Mistakes

  • i++ bhool gaye → infinite loop!
  • i <= arr.length → aakhri pe undefined (off-by-one) — < likho!
  • do-while ke while (...) ke baad semicolon lagana zaroori
  • for (...); — bracket ke baad semicolon = loop khaali chal gaya!
  • Array pe for...in → items nahi, indexes milte hai
  • while + continue — update pehle nahi toh hang!
  • Accumulator 0 se guna karna — factorial mein 1 se shuru karo

Interview Facts

  • for (;;) bhi infinite loop banata hai (teeno parts optional!)
  • do-while mein check BAAD mein hota hai — isliye 1 baar pakka
  • break sirf apne loop se bahar nikalta hai (nested mein sirf inner)
  • Nested loops = O(n²) — 1000 items pe 10 lakh steps!
  • arr.length ko variable mein cache karna minor optimization hai
  • var/let + setTimeout + loop = famous closure sawal (3 3 3 vs 0 1 2)
  • FizzBuzz = loop + conditions ka sabse famous combo
