Topic 01

JavaScript Kya Hai?

JavaScript ek high-level, interpreted programming language hai jo web pages ko interactive banati hai. Browser mein hi chalti hai — koi separate installation ki zarurat nahi.

Simple Si Baat

HTML = Web page ka skeleton (structure)
CSS = Web page ka makeup (style)
JavaScript = Web page ka brain (behavior, logic)

Kahan Kahan Chalti Hai?

  • Browser mein — Websites, web apps (React, Vue, Angular)
  • Server par — Node.js ke through backend bana sakte ho
  • Mobile mein — React Native se Android/iOS apps
  • Desktop mein — Electron se desktop apps (VS Code bhi Electron se bana hai!)
  • IoT / Robotics — Johnny-Five library se hardware control
Fun Fact: JavaScript ka naam "Java" se milta hai, par dono bilkul alag languages hain. JavaScript ka creator Brendan Eich ne sirf 10 din mein uska first version bana diya tha — 1995 mein!

// Pehla JavaScript program — Console mein hello likho console.log("Hello, Duniya!"); // Browser mein popup dikhao alert("Welcome to JavaScript!"); // Web page ka content change karo document.getElementById("title").textContent = "Naya Title!";
Topic 02

Variables Kya Hain?

Variable ek dabba (container) hai jismein tum koi value store kar sakte ho. Baad mein us value ko naam se access kar sakte ho, change bhi kar sakte ho.

Real Life Example: Socho ek dabba hai jiske upar "UMAR" likha hai. Andar tumne 25 likha. Jab bhi "UMAR" bologo, 25 milega. Kal agar badalna ho toh 26 kar do — dabba same rahega, value badli.

javascript
// Variable banana = Dabba bana + Naam likh + Value daal let naam = "Rahul"; // String dabba let umar = 25; // Number dabba let studentHai = true; // Boolean dabba // Value access karo console.log(naam); // "Rahul" console.log(umar); // 25 // Value change karo umar = 26; console.log(umar); // 26

Variable Naming Rules

  • Letters, digits, _, $ use kar sakte ho
  • Number se start nahi ho sakta — 1name galat hai
  • Spaces nahi — my name galat, myName sahi
  • Reserved words nahi use kar sakte — let, for, if, return etc.
  • Case sensitive hai — Naam aur naam alag hain
Best Practice: camelCase use karo — myFirstName, totalPrice, isActive. Meaningful naam rakho, x a temp avoid karo.

Topic 04

Scope Samjho — Block vs Function

Scope matlab "kahan tak visible hai". Variable kahin bana, par woh sirf usi area mein kaam karega jahan woh belong karta hai.

javascript
// ===== BLOCK SCOPE (let & const) ===== { let a = 10; const b = 20; console.log(a, b); // ✅ 10, 20 } console.log(a); // ❌ ReferenceError! Block ke bahar nahi milta // ===== FUNCTION SCOPE (var) ===== function test() { var c = 30; } console.log(c); // ❌ ReferenceError! Function ke bahar nahi milta // PAR var BLOCK scope follow nahi karta! if (true) { var d = 40; // if block hai, par var ko farak nahi padta } console.log(d); // ✅ 40 — Ye hi problem hai var mein!

Topic 05

Data Types — Overview

JavaScript mein 8 data types hain. Inhe 2 categories mein baanta jaata hai:

Primitive Types (7)

Ye single value store karte hain. Immutable hain (direct change nahi ho sakti). String, Number, Boolean, Null, Undefined, Symbol, BigInt

Reference Type (1)

Ye memory mein reference store karte hain. Mutable hain. Object (Arrays, Functions, Dates sab Objects hain internally)

String
Text data — letters, words, sentences
"Hello World"
Number
Integers aur decimals — sirf ek type
42, 3.14, -7
Boolean
Sirf 2 values — true ya false
true / false
Null
Intentionally empty — "kuch nahi"
null
Undefined
Value nahi mili — "abhi pata nahi"
undefined
Object
Key-value pairs — reference type
{name: "Rahul"}
Symbol
Unique identifier — ES6 mein aaya
Symbol("id")
BigInt
Badi numbers — limit nahi hai
9007199254740991n

Topic 07

String — Text Ka Data Type

String matlab text — koi bhi character sequence. Single quotes, double quotes, ya backticks se banta hai.

javascript
// Teen tarike se string bana sakte ho const s1 = 'Hello'; // Single quotes const s2 = "World"; // Double quotes const s3 = `Hello ${s2}`; // Backticks (Template Literal) console.log(s3); // "Hello World" // Template Literal mein expression bhi daal sakte ho const umar = 25; const msg = `Mera naam ${s1} hai aur umar ${umar} saal hai.`; console.log(msg); // Multi-line string — sirf backticks se const poem = ` Yeh pehli line hai Yeh doosri line hai Template literals amazing hain! `; // String properties & methods console.log("Hello".length); // 5 console.log("Hello".toUpperCase()); // "HELLO" console.log("Hello".toLowerCase()); // "hello" console.log("Hello".slice(1, 4)); // "ell" console.log("a,b,c".split(",")); // ["a", "b", "c"] console.log(" hello ".trim()); // "hello" console.log("Hello".includes("ell")); // true console.log("Hello".replace("H", "J")); // "Jello"
Important: String immutable hai. Matlab "Hello"[0] = "J" kaam nahi karega. String methods naya string return karte hain, original change nahi hota.

Number — Sab Tarah Ke Numbers

JavaScript mein sirf ek Number type hai — integer ho ya decimal, sab Number hai. Dusri languages jaise int, float, double alag nahi hain.

javascript
// Integer const age = 25; // Decimal (Floating Point) const price = 99.99; // Negative const temp = -5.5; // Special Values console.log(Infinity); // Infinity console.log(-Infinity); // -Infinity console.log(NaN); // NaN (Not a Number) // NaN aata hai jab number operation fail ho console.log("abc" * 5); // NaN console.log(NaN === NaN); // false! NaN khud se barabar nahi console.log(Number.isNaN(NaN)); // true — ye sahi tarika hai check karne ka // Number methods console.log((3.14159).toFixed(2)); // "3.14" console.log(parseInt("42px")); // 42 console.log(parseFloat("3.14abc")); // 3.14 console.log(Number.isInteger(42)); // true console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
Floating Point Bug: 0.1 + 0.2 === 0.30000000000000004 — ye JavaScript ka bug nahi, IEEE 754 standard ki limitation hai. Financial calculations ke liye toFixed() ya libraries use karo.

Topic 09

Boolean — True ya False

Boolean sirf 2 values rakhta hai: true aur false. Conditions, flags, switches mein use hota hai.

javascript
// Direct values const isLoggedIn = true; const isDeleted = false; // Comparison se bhi boolean milta hai console.log(10 > 5); // true console.log(10 === "10"); // false (type alag hai) console.log(10 == "10"); // true (type convert hua) // Boolean() function — kisi bhi value ko true/false mein convert karo console.log(Boolean(1)); // true console.log(Boolean(0)); // false console.log(Boolean("hello")); // true console.log(Boolean("")); // false console.log(Boolean(null)); // false console.log(Boolean(undefined)); // false

Falsy Values — Ye 8 values false ban jaati hain:

false, 0, -0, 0n, "", null, undefined, NaN

Baaki sab kuch truthy hai — empty array [], empty object {}, "false" string — sab true!

Topic 11

Object — King of Data Types

Object JavaScript ka sabse powerful data type hai. Key-value pairs store karta hai. Aur interesting baat — Array, Function, Date, RegExp, Map, Set — sab Objects hain!

javascript
// Object create karo — curly braces se const student = { name: "Rahul", age: 25, courses: ["Math", "Science"], address: { city: "Delhi", pin: 110001 }, greet: function() { return `Namaste, main ${this.name} hun!`; } }; // Access karo — dot notation console.log(student.name); // "Rahul" console.log(student.address.city); // "Delhi" // Access karo — bracket notation (dynamic key ke liye) const key = "age"; console.log(student[key]); // 25 // Modify karo (Object mutable hai!) student.age = 26; student.marks = 95; // Naya property add! // Method call karo console.log(student.greet()); // Check karo property hai ya nahi console.log("name" in student); // true console.log(student.hasOwnProperty("age")); // true // Keys & Values nikalo console.log(Object.keys(student)); // ["name", "age", "courses", ...] console.log(Object.values(student)); // ["Rahul", 26, [...], ...]
Array bhi Object hai! typeof [] dega "object". Array check karne ke liye Array.isArray([]) use karo.

Topic 12

Symbol — Unique Identity

Symbol ES6 (2015) mein aaya. Har Symbol() call se ek completely unique value banti hai. Do Symbols kabhi equal nahi hote.

javascript
// Symbol banana — har baar naya unique id const id1 = Symbol(); const id2 = Symbol(); console.log(id1 === id2); // false — dono alag hain! // Description de sakte ho (debugging ke liye) const userId = Symbol("user id"); console.log(userId.description); // "user id" // Object mein Symbol key — hidden property ban jaata hai const person = { name: "Rahul", [Symbol("secret")]: "hidden password" }; console.log(Object.keys(person)); // ["name"] — Symbol key nahi dikha! console.log(Object.getOwnPropertySymbols(person)); // [Symbol(secret)] // Global Symbol — kahin bhi access kar sakte ho const s1 = Symbol.for("appKey"); const s2 = Symbol.for("appKey"); console.log(s1 === s2); // true — same description = same symbol
Kab use karein? Symbol mostly libraries/frameworks mein internally use hota hai. Well-known symbols jaise Symbol.iterator, Symbol.toStringTag se objects ka behavior customize hota hai. Beginners ko zyada use karne ki zarurat nahi.
Topic 13

BigInt — Bade Numbers Ka Raja

JavaScript Number ki limit hai: 9,007,199,254,740,991 (2^53 - 1). Isse bade numbers ke liye BigInt use karo.

javascript
// Number ki limit cross karo const max = Number.MAX_SAFE_INTEGER; console.log(max); // 9007199254740991 console.log(max + 1); // 9007199254740992 ✅ console.log(max + 2); // 9007199254740992 ❌ Galat! Precision loss // BigInt banana — number ke baad 'n' lagao const big = 9007199254740991n; console.log(big + 1n); // 9007199254740992n ✅ Sahi! console.log(big + 2n); // 9007199254740993n ✅ Sahi! // BigInt() function se bhi bana sakte ho const huge = BigInt("9999999999999999999999999"); console.log(huge); // typeof console.log(typeof 10n); // "bigint" // ⚠️ BigInt aur Number mix nahi ho sakte // console.log(10n + 5); // ❌ TypeError! console.log(10n + BigInt(5)); // ✅ 15n
BigInt Limitations: BigInt ke saath Math methods nahi chalte. Number ke saath directly math nahi kar sakte. Decimal BigInt nahi bana sakte — 10.5n error dega.
