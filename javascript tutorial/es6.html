01 / Foundations

What changed in ES6?

ES6, also called ECMAScript 2015, introduced the building blocks used in modern JavaScript.

Cleaner syntax

let, const, arrow functions and template literals reduce boilerplate.

Better data handling

Destructuring, spread syntax, modules and collection methods make code easier to compose.

Guideline: prefer const by default, then use let when a value must change.
02 / Variables

let, const and var

Use block-scoped declarations so a variable stays close to the code that owns it.

javascript
const appName = "Study Lab";
let visits = 0;
visits += 1;
if (visits > 0) {
  const message = `Welcome to ${appName}`;
  console.log(message);
}

Scope in one line

let and const are block scoped. var is function scoped and is best avoided in new code.

03 / Functions

Arrow functions

Arrow functions are concise and inherit this from their surrounding scope.

javascript
const add = (a, b) => a + b;
const double = number => number * 2;
const makeUser = (name, role) => ({ name, role });
console.log(add(4, 6));
Remember: use regular methods for objects that need their own this; use arrows for callbacks and short transformations.
04 / Data extraction

Destructuring

Pull values from arrays and objects into named variables in one readable expression.

array
const colors = ["red", "blue"];
const [first, second] = colors;
console.log(first, second);
object
const user = { name:"Asha", age:24 };
const { name, age } = user;
console.log(name, age);
05 / Composition

Spread and rest

Spread expands values; rest gathers remaining values into an array.

javascript
const base = [1, 2];
const all = [...base, 3, 4];
const profile = { name:"Asha", online:true };
const updated = { ...profile, online:false };
function total(...numbers) { return numbers.reduce((sum, n) => sum + n, 0); }
06 / Strings

Template literals

Backtick strings support interpolation and clean multi-line output.

javascript
const name = "Asha";
const score = 92;
const summary = `${name} scored ${score}%`;
console.log(summary);
07 / Collections

Array methods

Build transformations by chaining small, predictable operations.

MethodReturnsUse it for
mapnew arraytransform every item
filternew arraykeep matching items
findone itemget the first match
reduceone valuecombine a collection
javascript
const prices = [10, 25, 40];
const discounted = prices.map(price => price * 0.9);
const total = discounted.reduce((sum, price) => sum + price, 0);
08 / Objects

Objects and classes

Classes are syntax over JavaScript's prototype system. Use them when instances share behavior.

javascript
class Account {
  constructor(owner) { this.owner = owner; this.balance = 0; }
  deposit(amount) { this.balance += amount; return this; }
  summary() { return `${this.owner}: ${this.balance}`; }
}
09 / Async code

Promises and async/await

Use async functions to write asynchronous flows that read like synchronous code.

javascript
const wait = ms => new Promise(resolve => setTimeout(resolve, ms));
async function loadMessage() {
  await wait(300);
  return "Data loaded";
}
loadMessage().then(console.log).catch(console.error);
Production habit: wrap awaited work in try...catch when the failure needs a user-facing response.
