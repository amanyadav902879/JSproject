Variables Real Life Mein — Aise Samjho!

Programming variables ko real life cheezo se compare karo, toh kabhi nahi bhoologe. Neeche 6 analogies hain jo variable ke har concept — storage, update, scope, const — mazaak mein samjha dengi. Har card ke saath code bhi hai, so jaisa socha waisa hi likha jata hai!

📦

Variable = Label Wala Dabba

Ghar ka dabba socho — upar label likha hai "Chini", andar chini hai. Variable bhi waise hi hai: naam (label) aur value (andar ka saman). Dabbe ka label same rehta hai, andar ka saman badal sakte ho — bas yahi reassignment hai!

// Dabbe mein saman rakha let dabba = "Chini"; // Saman badal diya, label wahi dabba = "Namak";
🏷️

var vs let vs const = Hotel Rooms

var = purana hostel — ek room do baar allot ho jaye, koi bhi ghus jaye (function scope). let = naya hotel — ek room ek baar, aur apni floor (block) tak hi simit. const = VIP suite — guest change nahi hoga, par suite ke andar ka furniture rearrange kar sakte ho!

const vipSuite = { tv: "Sony" }; vipSuite.tv = "Samsung"; // Allowed! // vipSuite = {} → TypeError!
💰

Bank Balance = let Variable

Tumhara bank balance ek let variable hai. Salary aayi toh badh gaya, shopping ki toh ghat gaya. Value baar-baar update hoti rehti hai — isiliye paisa jaisi changing cheezein let se banti hain, const se nahi.

let balance = 5000; balance += 20000; // salary aayi! balance -= 1500; // shopping kar li
🎂

Birthdate = const Variable

Tumhari age har saal badalti hai (let), par birthdate kabhi nahi badalti (const). Jo cheez kabhi change nahi hoti — jaise GST rate, PI, tumhara janam din — uske liye const use karo. Galti se change nahi hoga, code secure rahega.

const BIRTH_YEAR = 2005; let age = 2025 - BIRTH_YEAR; age++; // birthday mubarak! 🎉
📱

Contact List = Object Variable

Phone ka contact ek object variable hai — ek naam ke neeche kai details (number, email). Friend ka number badal sakte ho (property update allowed), par us friend ko dusre se replace nahi kar sakte (const reassign nahi hota).

const dost = { naam: "Amit", phone: "9999-8888" }; dost.phone = "7777-6666"; // OK!
🎮

Game Score = Live Update Hota Variable

Subway Surfers khelte waqt score har coin ke saath badalta hai — yehi variable ka kaam hai. Current score let hai, high score bhi let hai (record toot sakta hai), par game ka naam const hai!

let score = 0; let highScore = 1250; score = score + 10; // coin mila if (score > highScore) { highScore = score; }

Real Apps Mein Variables — Instagram se Zomato Tak

Jo tum ab seekh rahe ho, wahi code har bade app ke andar chal raha hai — Instagram, Zomato, WhatsApp, YouTube, GPay. Dekho kaise! Har card mein real app ka chhota sa logic hai jo tum abhi samajh sakte ho.

Instagram — Follower Count

Har baar jab koi follow karta hai, ek variable badhta hai. Unfollow par ghata. Profile par jo number dikhta hai, wo ek live variable hai!

let followers = 1250; followers++; // koi follow kar gaya followers--; // koi unfollow kar gaya console.log(followers);

Zomato — Cart Ka Bill

Item ka price menu se aata hai (fixed = const), quantity tum change karte ho (let). Bill = price × quantity + GST. Yehi niche Workshop ka Task 4 hai!

const price = 250; // menu ka price let qty = 2; // tumne badhaya let total = price * qty; total += total * 0.05; // GST laga!

WhatsApp — Unread Badge

Wo laal badge jo unread messages dikhata hai? Ek variable hai. Chat kholte hi 0 ho jata hai, naya message aate hi badh jata hai.

let unread = 5; unread++; // naya message aaya unread = 0; // chat khol li — badge gayab!

YouTube — Views & Likes

Har second views badhte hain. Numbers itne bade hote hain ki "1.5M" mein dikhaate hain — wo conversion bhi variables se hi hoti hai.

let views = 1520000; let likes = 98000; views++; // tumne video dekhi! let viewsInM = (views / 1000000).toFixed(1); console.log(viewsInM + "M views");

GPay — Balance Update

Payment karte hi balance ghata, paisa aaya toh badha. Banking apps ka core yehi let variable hai — bas upar se security ki chhat!

let balance = 8000; balance -= 450; // chai-paani pi liya balance += 25000; // salary aa gayi 😎 console.log("Balance: Rs." + balance);

Games — High Score Logic

"NEW HIGH SCORE!" tabhi dikhta hai jab current score, high score se bada ho. Ye comparison do variables ke beech hota hai.

let currentScore = 0; let highScore = 1250; currentScore = 1400; // game khela! if (currentScore > highScore) { highScore = currentScore; }

Workshop — Apne Haath Se Code Karo

Yeh tasks sirf padhne ke liye nahi hain — karne ke liye hain! Har task upar wale Code Playground mein ya apne browser ke console mein karo (F12 dabao → Console tab). Atka toh pehle Hint kholo, phir bhi na ho toh Solution dekh kar dobara khud se likho. Ek task complete karo, tabhi agle par jao!

Task 1: Identity Card Easy

  1. apnaNaam, age, city, hobby variables banao
  2. Soch kar decide karo — kaunsa const, kaunsa let?
  3. Template literal se 1-2 intro lines banao
  4. console.log() se print karo
Jo value kabhi nahi badlegi (naam, city, hobby) usse const rakho. Age badh sakti hai — let rakho. Confusion ho toh const se shuru karo, error aaye toh let karna!
const fullName = "Rahul Sharma"; let age = 20; const city = "Delhi"; const hobby = "Cricket"; console.log(`Mera naam ${fullName} hai.`); console.log(`Main ${city} mein rehta hoon.`); console.log(`Meri age ${age} saal hai aur mujhe ${hobby} khelna pasand hai.`);

Task 2: Reassignment Detective Easy

  1. let score = 5 banao, har step par console.log karo
  2. score = 10 karo, phir score = score + 5
  3. Ab score *= 2 try karo (shorthand!)
  4. const level = 1 banao aur use change karne ki koshish karo
  5. Error message dhyan se padho aur note karo
const par error aayega: "TypeError: Assignment to constant variable" — yahi expected hai, ye galti nahi! Error ka message copy karke rakh lo — interview mein poocha jata hai.
let score = 5; console.log(score); // 5 score = 10; console.log(score); // 10 score = score + 5; console.log(score); // 15 score *= 2; console.log(score); // 30 const level = 1; level = 2; // ❌ TypeError: // Assignment to constant variable

Task 3: Counter Machine Easy

  1. let count = 0 banao
  2. 3 baar count++ likho (haath se, copy-paste nahi!)
  3. 1 baar count-- karo
  4. Final print: "Final count: X"
count++ ka matlab hai count = count + 1. Har line ke baad console.log(count) lagao toh value kaise badal rahi hai dikhega. Ye like button ka basic logic hai!
let count = 0; count++; count++; count++; console.log(count); // 3 count--; console.log("Final count: " + count); // Final count: 2

Task 4: Shopping Bill Medium

  1. const price = 250, let qty = 3 banao
  2. Subtotal nikalo = price × qty
  3. GST 18% nikalo = subtotal × 0.18
  4. Grand total print karo — "Total: Rs.XXX (GST samet)"
Pehle subtotal = price * qty. Phir gst = subtotal * 0.18. Phir grandTotal = subtotal + gst. Har value alag variable mein rakho — chhote steps bade formula se better hain!
const price = 250; let qty = 3; let subtotal = price * qty; let gst = subtotal * 0.18; let grandTotal = subtotal + gst; console.log("Subtotal: Rs." + subtotal); // Subtotal: Rs.750 console.log("GST (18%): Rs." + gst); // GST (18%): Rs.135 console.log("Total: Rs." + grandTotal + " (GST samet)"); // Total: Rs.885 (GST samet)

Task 5: Temperature Converter Medium

  1. let celsius = 40 banao
  2. Formula use karo: fahrenheit = (celsius × 9/5) + 32
  3. Dono values print karo
  4. Bonus: celsius = 0 aur 100 karke check karo (paani ka freezing/boiling point!)
Formula seedha JS mein likho — (celsius * 9) / 5 + 32. JS maths khud karega. Template literal se `40°C = 104°F` jaisa sundar output banao!
let celsius = 40; let fahrenheit = (celsius * 9) / 5 + 32; console.log(`${celsius}°C = ${fahrenheit}°F`); // 40°C = 104°F celsius = 100; fahrenheit = (celsius * 9) / 5 + 32; console.log(`${celsius}°C = ${fahrenheit}°F`); // 100°C = 212°F

Task 6: Swap Challenge Hard

  1. drink1 = "Chai", drink2 = "Coffee" banao
  2. temp variable ki madad se values swap karo
  3. Bonus: bina teesre variable ke swap karo — [drink1, drink2] = [drink2, drink1]
  4. Dono tariko ke output compare karo
Order matter karta hai! Pehle temp = drink1 (safe rakho), phir drink1 = drink2, phir drink2 = temp. Order galat hua toh value kho jayegi. Destructuring wala tarika ekdum modern hai — interview mein bonus point!
let drink1 = "Chai"; let drink2 = "Coffee"; // Tarika 1: temp variable let temp = drink1; drink1 = drink2; drink2 = temp; console.log(drink1, drink2); // Coffee Chai // Tarika 2: destructuring (modern!) let a = 1, b = 2; [a, b] = [b, a]; console.log(a, b); // 2 1

Naming Rules — Kya Karo, Kya Na Karo

  • camelCase use karo — userAge, totalPrice
  • Meaningful naam do — studentCount sahi hai, x galat
  • Constant UPPERCASE likho — const MAX_SPEED = 120
  • Naam letter, _ ya $ se start hona chahiye
  • Number se start mat karo — let 1name ❌
  • Space wala naam nahi — let my name ❌
  • Reserved words nahi — let, class, if, new ❌
  • Dhyan rakho: age aur Age alag hain — case-sensitive!

Interview Facts — Ratta Nahi, Samajh Lo

  • Falsy values sirf 6 hain: false, 0, "", null, undefined, NaN
  • typeof null === "object" — 1995 ka historic bug
  • typeof NaN === "number" — irony hai bhai 😅
  • NaN === NaN → false — NaN kisi ke barabar nahi
  • const object/array ke andar ka change allowed hai — reference lock hota hai
  • = assign karta hai, == loose compare, === strict compare
  • JS dynamically typed hai — ek variable koi bhi type rakh sakta hai
  • Default choice const, change ho toh let, var kabhi nahi
