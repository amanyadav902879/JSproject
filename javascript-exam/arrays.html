1. Create & Access

3. Add & Remove — Shuru Se

6. Cut & Copy

slice() / splice()

slice = hissa COPY karo (asli safe), splice = asli array se kaat do! Naam milta-julta, kaam bilkul alag!

Power #1

Create & Index — Line Mein Khada Karo 🔢

Array banane ke liye bas [ square brackets ] aur andar items comma se alag. Har item ko apna index number milta hai — par dhyan se, ginti shuru hoti hai... 0 se! 1 se nahi. Yahi dunia ka sabse famous beginner surprise hai!

// Syntax: let NAAM = [item1, item2, item3]; let fruits = ["🍎", "🍌", "🍇", "🥭"]; // [0] [1] [2] [3] ← indexes! console.log(fruits[0]); // "🍎" — index 0 = PEHLA item console.log(fruits[3]); // "🥭" — index 3 = CHAUTHA item console.log(fruits[4]); // undefined — index 4 pe koi nahi! 😢 // Update karna — index pe naya item rakho: fruits[1] = "🍉"; // 🍌 hata, 🍉 aa gaya console.log(fruits); // ["🍎", "🍉", "🍇", "🥭"] // Length — ginti (items ka NUMBER, index se 1 zyada!) console.log(fruits.length); // 4 items console.log(fruits[fruits.length - 1]); // LAST item ka pakka formula!
BOMB ALERT: Index 0 Se Shuru Hota Hai!

Tumne fruits[1] poocha aur socha "pehla fruit milega"? Nahi — doosra milega! 🤯 Kyunki JS (aur lagbhag saari programming languages) ginti 0 se shuru karti hai. Yaad rakhne ka tareeka: index = item se kitne kadam aage — pehle item se 0 kadam, doosre se 1 kadam...
Aur arr[4] jaise bahaar ka index poocha toh error nahi aata — sirf undefined milta hai (silent failure — Ch5 wala concept yaad hai na?). Isliye hamesha check karo: arr.length se pehle!

Last Item Ka Magic Formula

Kitna bhi bada array ho, last item nikalne ka pakka formula: arr[arr.length - 1]. Kyun - 1? Kyunki length ginti batata hai (5 items = length 5), par aakhri index usse ek kam hota hai (0,1,2,3,4 — last = 4!). Ye formula har codebase mein milega — aaj hi ratta maar lo! 😄

Power #2 & #3

push / pop / shift / unshift — Items Aaye, Items Gaye 🚪

Array zinda cheez hai — items aate-jaate rehte hai! End se khelna easy hai: push (aakhri mein jodo) aur pop (aakhri se nikalo). Shuru se khelna thoda dramatic hai: shift (pehla niklo, sab peeche khisko!) aur unshift (shuru mein ghuso, sab aage khisko!). Chaaron yaad karo — interviews mein pakka aate hai!

// END se: push (jodo) + pop (nikalo) let basket = ["🍎", "🍌"]; basket.push("🍇"); // END mein 🍇 gaya console.log(basket); // ["🍎", "🍌", "🍇"] console.log(basket.length); // 3 let nikla = basket.pop(); // aakhri item BAHAR + haath mein aaya! console.log(nikla); // "🍇" — pop RETURN karta hai! console.log(basket); // ["🍎", "🍌"]
BOMB ALERT: push Ka Return Value = Array NAHI, LENGTH Hai!

let x = basket.push("🍇"); — tumne socha x mein array aayega? Nahi bhai! push return karta hai nayi LENGTH (kitne items ho gaye), pop/shift return karte hai nikla hua item! Isliye basket = basket.push(item) likha toh basket kharab — usme sirf ek number reh jayega! 😱 Yaad rakho: push badalta hai ASLI array ko — assign karne ki zaroorat hi nahi!

// SHURU se: shift (pehla niklo) + unshift (shuru mein ghuso) let line = ["🧍", "🧍‍♀️", "🧍‍♂️"]; let aageWala = line.shift(); // pehla ticket leke chala! console.log(aageWala); // "🧍" console.log(line); // ["🧍‍♀️", "🧍‍♂️"] — dono EK jagah PEECHE khisak gaye! line.unshift("🧔"); // VIP line ke shuru mein ghusa! console.log(line); // ["🧔", "🧍‍♀️", "🧍‍♂️"] — sabka index BADAL gaya!

Kaunsa Kab? — Memory Trick

Push = Piche se daalo, Pop = Piche se nikalo. shift = pehle wala "shift ho gaya" (bahar!). unshift = shift ka ULTA. Real life: playlist mein gaana add = push, "next gaana" bajana = shift (aage wala nikla, baaki aage aaye!), reload/undo history = pop. Yaad hai Ch4 ka infinite loop? Waise hi — while(arr.length > 0) + pop() = array khaali hone tak chalne wala loop! 🔥

Power #4

length + Loop — Array Ka Asli Khel 🔄

Array bana ke rakha toh kya fayda — har item pe kaam karna hai! Aur kaam karne wala kaun? Ch4 ka loop! Array + loop ka jodi ITNI famous hai ki JS ne loop ka special version banaya — for...of. Aaj dono seekho, dono aage har jagah chalenge!

// Style 1: classic for loop — index chahiye toh let marks = [85, 92, 78, 95]; for (let i = 0; i < marks.length; i++) { console.log("Student " + i + ": " + marks[i]); } // i = 0 se length-1 tak — HAR index ghoomega! // Style 2: for...of — sirf VALUE chahiye toh (clean!) for (let mark of marks) { console.log(mark); } // "of" = har item ke ANDAR ka value seedha de deta hai!
BOMB ALERT: length Nahi Toh One-Off Bug!

for (let i = 0; i < 4; i++) — length ki jagah number hardcode kiya? Kal array mein 5th student aaya, aur tumhara loop usse ghaur bhi nahi karega! Isliye hamesha i < arr.length likho — array jitna bada, loop utna chalega, khud ba khud!
Aur ek trap: i <= arr.length (<= lagaya) — aakhri iteration mein arr[length] = undefined! One-off bugs JS ka favourite shaitan hai 😈

Power #5 & #6

Search + slice/splice — Dhoondo, Kaato 🔍✂️

"Kya ye item mere array mein hai?" — includes() poochta hai, true/false deta hai. "Hai toh kaha hai?" — indexOf() position batata hai (nahi mila toh -1). Aur jab array ka tukda chahiye ya beech se hataana hai — slice aur splice. Par dhyan: ye dono TWINS jaisi dikhti hai, kaam bilkul alag!

// SEARCH — includes (hai ya nahi?) + indexOf (kaha hai?) let fruits = ["🍎", "🍌", "🍇"]; console.log(fruits.includes("🍌")); // true — mil gaya! console.log(fruits.includes("🍉")); // false — nahi hai console.log(fruits.indexOf("🍇")); // 2 — index 2 pe hai console.log(fruits.indexOf("🍉")); // -1 — "milA hi nahi" ka signal if (fruits.includes("🍎")) { console.log("Apple hai, kha lo! 🍎"); }
BOMB ALERT: slice COPY karta hai, splice KAAT deta hai!

Naam sirf ek letter ka farak, natija zameen-aasmaan ka!
slice(1, 3) → array ka hissa COPY karke naya array deta hai — asli array bilkul safe! (end index include nahi hota!)
splice(1, 3) → asli array se 3 items KAAT deta hai — permanent delete! 😱
Galti se splice jagah slice likh diya toh data gaya — isliye rule: copy chahiye = slice (c se copy!), kaatna hai = splice (p se Permanent!)

// SLICE — copy nikalo (asli safe raha!) let nums = ["a", "b", "c", "d", "e"]; let part = nums.slice(1, 3); // index 1 SE, 3 TAK (3 exclude!) console.log(part); // ["b", "c"] console.log(nums); // ["a","b","c","d","e"] — SAFE! ✅ // SPLICE — beech se kaato (permanent!) nums.splice(1, 2); // index 1 se, 2 items DELETE console.log(nums); // ["a", "d", "e"] — b,c GAYE! ❌ nums.splice(1, 0, "X"); // 0 delete, index 1 pe "X" INSERT! console.log(nums); // ["a", "X", "d", "e"]

indexOf item na mile toh -1 return karta hai — ye koi error nahi, ek signal hai! Isliye check likhne ka standard tareeka: if (arr.indexOf("x") === -1) { ... "x nahi mila" }. Bonus Power

map / filter / join — Pro Coders Ke Hatyaar ✨

Ye 3 methods Ch5 ke callbacks ka asli khel dikhate hai — function ko array ke har item pe chalao! Abhi sirf intro hai (aage inki alag gehai hai), par dekh lo — ye teeno JS ka sabse pyara hissa hai. Interview mein bhi roz aate hai!

// MAP — har item pe function chalao, NAYA array lo let nums = [1, 2, 3, 4]; let double = nums.map(function(n) { return n * 2; }); console.log(double); // [2, 4, 6, 8] — nums SAFE hai! // FILTER — sirf pass hone wale items ka NAYA array let big = nums.filter(function(n) { return n > 2; }); console.log(big); // [3, 4] — chhote gaye! // JOIN — array ko string bana do (comma se) console.log(["🍎", "🍌"].join(" + ")); // "🍎 + 🍌" // REVERSE — ulta kar do (asli array badal jaata hai!) console.log([1, 2, 3].reverse()); // [3, 2, 1]
BOMB ALERT: map/filter NAYA array dete hai — asli SAFE!

nums.map(...) ka jawab kisi variable mein daalna zaroori hai — sirf nums.map(...) likha toh naya array ban ke ud gaya (use nahi hua!). Aur yaad rakho: map/filter asli array ko nahi chhedte — naya dete hai. Splice/reverse/sort asli ko chhedte hai! Ye "mutate vs non-mutate" wala sawal interviews ka favourite hai 😎

🟢 Easy Task 2: sumOf() — Saare Numbers Ka Total

Function sumOf(arr) likho jo numbers array ka total return kare. Test: sumOf([10, 20, 30, 40]) → 100. Ch4 ka accumulator pattern + Ch5 ka function + Ch6 ka array — TRIO COMBO! 🔥

Idea: let total = 0 banao (0 se shuru!), loop se har item add karo: total += arr[i]. End mein return total — return function ke andar, print bahar!
function sumOf(arr) {
  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    total += arr[i];
  }
  return total;
}

console.log(sumOf([10, 20, 30, 40])); // 100
console.log(sumOf([5, 5, 5]));        // 15

// for...of se aur clean:
function sumOf2(arr) {
  let t = 0;
  for (let n of arr) t += n;
  return t;
}
🟡 Medium Task 3: findMax() — Sabse Bada Number

Function findMax(arr) likho jo array ka sabse bada number return kare — Math.max ke bina! Test: findMax([42, 17, 88, 5]) → 88. Ch5 ka maxOf ab poori line pe lagega!

Idea: max = arr[0] (pehla ko max maan lo!). Loop index 1 se chalao — har item se poocho: if (arr[i] > max) max = arr[i]. Jo jeet jaaye wahi raja!
function findMax(arr) {
  let max = arr[0];            // pehla = default raja
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
      max = arr[i];            // naya raja aa gaya!
    }
  }
  return max;
}

console.log(findMax([42, 17, 88, 5])); // 88
console.log(findMax([-5, -2, -9]));    // -2 (negative bhi sahi!)
🟡 Medium Task 4: evensOf() — Sirf Even Numbers Ki Nayi Line

Function evensOf(arr) likho jo sirf even numbers ki NAYI array return kare (original safe rahe!). Test: evensOf([1, 2, 3, 4, 5, 6]) → [2, 4, 6]. Bonus: wahi kaam filter() se 1 line mein!

Idea: Khaali array banao let result = [], loop mein even check (Ch5 ka isEven yaad hai? n % 2 === 0) aur even ho toh result.push(n). End mein result return!
function evensOf(arr) {
  let result = [];              // nayi khaali line
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] % 2 === 0) {
      result.push(arr[i]);      // even? line mein jao!
    }
  }
  return result;
}

console.log(evensOf([1, 2, 3, 4, 5, 6])); // [2, 4, 6]
console.log(evensOf([7, 9]));             // []

// Bonus — filter() se 1 liner:
function evensOf2(arr) {
  return arr.filter(n => n % 2 === 0);
}
🔴 Hard Task 5: reverseOf() — Line Ulto Chalo

Function reverseOf(arr) likho jo ulti array return kare — .reverse() method ke bina! Test: reverseOf([1, 2, 3]) → [3, 2, 1]. Original array ko chhedna mana hai!

Idea: Loop ko ULTA chalao: for (let i = arr.length - 1; i >= 0; i--) — last se shuru, 0 tak. Har item nayi array mein push karte jao!
function reverseOf(arr) {
  let result = [];
  for (let i = arr.length - 1; i >= 0; i--) {
    result.push(arr[i]);
  }
  return result;
}

console.log(reverseOf([1, 2, 3]));        // [3, 2, 1]
console.log(reverseOf(["a", "b", "c"]));  // ["c","b","a"]

// Bonus — while + pop se (stack trick!):
function reverseOf2(arr) {
  let copy = arr.slice();  // asli bachao!
  let out = [];
  while (copy.length > 0) out.push(copy.pop());
  return out;
}
🔴 Hard Task 6: myIndexOf() + countItem() — Detective Khoja

Do functions likho (built-in ke bina!): myIndexOf(arr, item) — item mila toh uska index return, nahi toh -1. Aur countItem(arr, item) — item kitni baar hai wo ginti return kare!

Idea: myIndexOf: loop chalao, if (arr[i] === item) return i; — milte hi turant bahar (early return!). Loop khatam ho gaya matlab nahi mila → return -1. countItem: wahi loop, milte hi count++, end mein count return!
function myIndexOf(arr, item) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === item) return i;  // mila! turant bahar
  }
  return -1;                        // poora ghooma, nahi mila
}

function countItem(arr, item) {
  let count = 0;
  for (let x of arr) {
    if (x === item) count++;
  }
  return count;
}

console.log(myIndexOf([10, 20, 30], 20));      // 1
console.log(myIndexOf([10, 20, 30], 99));      // -1
console.log(countItem(["🍎","🍌","🍎"], "🍎")); // 2

Kab Kya Use Kare?

  • push/pop — end se kaam (stack, undo history)
  • shift/unshift — line/queue (messages, playlist)
  • for...of — sirf values chahiye
  • for + index — position ya update karna hai
  • includes — haan/na sawal
  • indexOf — position chahiye
  • slice — copy/hissa chahiye (pagination!)
  • splice — beech se hatana/insert karna
  • map/filter — naya array banao (transform/check)

Common Mistakes

  • Index 0 se shuru — arr[1] doosra item hai!
  • Last item = arr[arr.length - 1] — length nahi!
  • Bahaar ka index → undefined (error nahi aata!)
  • push ka return = length, array nahi — arr = arr.push() MAT karo!
  • slice ≠ splice — copy vs permanent cut!
  • Loop mein i <= arr.length → undefined ka surprise!
  • Length hardcode karna — i < 4 nahi, i < arr.length!
  • for...in array pe — index STRING milta hai, avoid!
  • Numbers pe bina compare fn ke sort() — galat order!

Interview Facts

  • Index 0 se kyunki memory offset — pehla item 0 kadam door
  • typeof [] = "object" — array check: Array.isArray(arr)
  • Arrays reference type hai — b = a copy NAHI, same array!
  • const array mein push chalta hai — reference fix, content free!
  • shift/unshift sabka index badalta hai — O(n) operation!
  • map/filter NAYA array — original untouched (non-mutating)
  • splice/reverse/sort ASLI array badalte hai (mutating!)
  • indexOf(NaN) = -1 — NaN kabhi barabar nahi! includes(NaN) kaam karta hai
  • Empty check: arr.length === 0 — hamesha!
