Concept

Conditional Kya Hota Hai? 🤔

Conditional statements ka kaam hai decisions lena. Tum roz life mein yahi karte ho: "AGAR baarish ho rahi hai → chhata le jao, WARNA chashma le jao." Bas yahi if-else hai! Code ab khud soch sakta hai — kab kya karna hai.

Traffic Signal Analogy

Traffic signal ek live conditional hai! Signal green hai? → Chalo. Red hai? → Ruko. Yellow hai? → Ready ho jao. Signal condition check karta hai aur uske hisaab se action hota hai.

Programming mein bhi same: if (light === "green") → chalne wala code chalta hai, warna rukne wala. Pichle chapter ke comparison operators (>, ===) aur logical operators (&&, ||) se hi yeh conditions banti hain — ab unka asli game shuru!

condition? (age >= 18)
TRUE ✅Voting allowed 🗳️
FALSE ❌Abhi ruko ⏳
// Decision ka formula: // 1. Condition likho (jo true/false ho) // 2. TRUE wala rasta → if block // 3. FALSE wala rasta → else block let age = 20; if (age >= 18) { // condition check hui console.log("Voting allowed 🗳️"); // TRUE → ye chalega } else { console.log("Abhi ruk ja ⏳"); // FALSE → ye hota }

JavaScript mein 4 decision tools hain — har ek ka apna mazaaur (use case). Sab cards dekho, phir ek-ek karke detail mein 👇

1. if

if (condition) { ... }

Sabse basic — "agar ye true hai toh ye kaam karo". False hua toh kuch nahi hota, seedha aage.

2. if-else

if (...) { A } else { B }

Do raste — condition true → A, false → B. Hamesha dono mein se EK pakka chalega.

3. else-if Ladder

if ... else if ... else if ... else

2 se zyada options ho toh — upar se neeche check hota hai, pehla true wala chalta hai.

4. switch

switch (x) { case 1: ... break; }

Ek variable ke fixed values check karne ka clean tarika — jaise remote ke buttons ya menu.

5. Nested if

if () { if () { ... } }

Condition ke andar hi condition — jaise ATM: pehle PIN check, phir balance, phir cash.

6. Truthy / Falsy

if (value) — bina comparison!

JS har value ko true ya false jaisa maan leta hai. 6 falsy values yaad rakhna — interview ka favourite!

Tool #1

if Statement — Pehla Darwaza 🚪

if kehta hai: "Agar yeh condition true hai, toh mere andar wala code chalao. Nahi hai? Koi baat nahi — mujhe skip karo, aage badho."

// Syntax: if (condition) { // yeh code SIRF tab chalta hai // jab condition true ho } // Example 1: Speed alert 🚗 let speed = 95; if (speed > 80) { console.log("Bhai slow karo! Chall katega 🚨"); } // Example 2: Chhata check ☂️ let isRaining = true; if (isRaining) { console.log("Chhata le jao!"); } console.log("Ghar pahunche ✅"); // ye HAMESHA chalega
3 Rules Jo Kabhi Mat Bhoolna

1. Condition round brackets ( ) mein, code curly brackets { } mein.
2. if ke baad semicolon (;) nahi lagta — if (x > 5); likha toh bug!
3. Condition ki value boolean hoti hai — true ya false. (Truthy/falsy ka khel aage dekhoge 👀)

Tool #2

if-else — Do Raste Wala Game ⚖️

Kabhi-kabhi dono taraf ka plan hona chahiye: "pass hue toh party, fail hue toh padhai." else bhai kaam aate hai — condition true toh if block, false toh else block. Hamesha ek pakka chalega!

// Result ka faisla 📋 let marks = 82; if (marks >= 35) { console.log("PASS! Party kab? 🎉"); } else { console.log("Fail... agle saal isi din 📚"); } // "PASS! Party kab? 🎉" // Instagram login ka core logic 📸 let enteredPass = "rahu@123"; let savedPass = "rahu@123"; if (enteredPass === savedPass) { console.log("Login successful! Feed dikha do 📱"); } else { console.log("Galat password! Dobara try karo ❌"); }
BOMB ALERT: = vs === Condition Mein!

Interview ka sabse bada trap: if (x = 5) mein = likh diya toh comparison nahi, ASSIGNMENT ho jayegi! x mein 5 chala jayega, aur 5 toh truthy hai — toh block hamesha chalega, chahe condition kuch bhi ho. 😱 Hamesha === ya >= jaise comparison operators hi use karo conditions mein!

Tool #3

else-if Ladder — Seedhi Ki Tarah 👣

2 se zyada options ho toh? Jaise grades: A+, B, C, Fail. Ya traffic light: green/yellow/red. Tab else if ki seedhi banao — JS upar se neeche check karta hai aur PEHLA true wala rung chalata hai. Neeche wale sab skip!

// Grade machine 📊 let marks = 82; if (marks >= 90) { console.log("Grade A+ 🏆"); // 82 >= 90? Nahi. } else if (marks >= 75) { console.log("Grade B 👍"); // 82 >= 75? HAAN! → ye chalega } else if (marks >= 60) { console.log("Grade C 😊"); // yaha tak pahunchega hi nahi } else { console.log("Padhai karo bhai 📚"); } // Traffic light 🚦 let light = "yellow"; if (light === "red") { console.log("RUKO 🛑"); } else if (light === "yellow") { console.log("READY ho jao 🟡"); } else if (light === "green") { console.log("CHALO 🟢"); } else { console.log("Signal kharab hai! 😅"); }
Order Ka Khel — Bahut Important!

Ladder mein sabse strict condition sabse UPAR rakho. Agar marks >= 60 pehle likh diya aur >= 90 baad mein — toh 95 marks wala bhi Grade C pa lega! Kyunki 95 >= 60 pehle hi true ho gaya aur pehla true hi chalta hai. Order galat = logic disaster!

Tool #4

switch Statement — Menu Se Order Karo 🍽️

Jab ek hi variable ke kai fixed values check karni ho (jaise hafta ka din, menu ka item, remote ka button), toh lambi else-if ladder ki jagah switch clean lagta hai. switch kehta hai: "Jo case match hua, wahi order banao!"

// Syntax: switch (variable) { case value1: // variable === value1? // kaam karo break; // phir switch se bahar! case value2: // dusra kaam break; default: // koi case match nahi hua // default kaam } // Restaurant menu 🍽️ let order = "pizza"; switch (order) { case "burger": console.log("Burger banao 🍔 — ₹99"); break; case "pizza": console.log("Pizza banao 🍕 — ₹299"); break; case "momos": console.log("Momos banao 🥟 — ₹79"); break; default: console.log("Ye humari menu mein nahi hai! 🙃"); } // "Pizza banao 🍕 — ₹299"
BOMB ALERT: break Bhool Gaye Toh? (Fall-Through)

break likhna bhool gaye toh JS matching case se aage ke SAARE cases bhi chala deta hai — bina kisi check ke! Isko fall-through kehte hai:

  • Case "pizza" match hua, par break nahi tha → burger AUR momos wala code bhi chal gaya 😱
  • Fix: har case ke end mein break; lagao
  • Exception: intentionally group karna ho — case "Sat": case "Sun": → "Weekend!" (yeh feature hai, bug nahi!)
switch ya else-if? Kab Kya?

switch: EK variable ke fixed values check karna ho (day === "Monday", choice === 3). Readable aur clean.
else-if: ranges check karni ho (marks >= 90) ya complex conditions ho (age > 18 && hasID).
Note: switch internally === (strict comparison) use karta hai!

Tool #5

Nested if — Andar Wali Condition 🔐

Ek if ke andar dusra if = nested if. Logic: "pehle yeh check karo — agar wo pass hua, TAB aage ki condition check karo." Jaise ATM: pehle card valid? → phir PIN sahi? → phir balance hai? → tab cash milega!

// ATM ka nested logic 🏧 let cardValid = true; let pin = 1234; let enteredPin = 1234; let balance = 5000; let amount = 2000; if (cardValid) { // card theek hai, TAB PIN check karo if (enteredPin === pin) { // PIN sahi hai, TAB balance check karo if (amount <= balance) { console.log("Le lo paise 💵 — bache:", balance - amount); } else { console.log("Balance kam hai! ❌"); } } else { console.log("Galat PIN! 🔴"); } } else { console.log("Card invalid hai ❌"); }
Nested Zyada Gehra Ho Toh? && Use Karo!

2-3 level se zyada nested code padhna mushkil ho jata hai (isko "pyramid of doom" bhi kehte hai 😄). Jab conditions independent ho, && se jodo: if (cardValid && enteredPin === pin && amount <= balance) — ek hi line mein! Nested sirf tab use karo jab har level pe alag-alag error message dikhana ho.

Tool #6

Truthy / Falsy — Bina Comparison Ke Conditions! 👻

Sabse mazedaar cheez: JS mein condition mein koi bhi value daal sakte ho — number, string, null, kuch bhi! JS khud decide karta hai ki wo value "true jaisi" (truthy) hai ya "false jaisi" (falsy). Comparison likhe bina conditions!

6 Falsy Values — YAAD KAR LO RATTA MAAR KE!

false, 0, "" (empty string), null, undefined, NaN — bas yeh 6 values falsy hai. Inke alawa SAB KUCH truthy! 😄

Trick: "6 falsy" ko yaise yaad karo — 0 (paisa nahi), "" (khaali), false (jhooth), null (khaali dabba), undefined (dabba hi nahi), NaN (galat maths).

// Falsy examples — block NAHI chalega if (0) { console.log("chalega?"); } // 0 falsy → skip if ("") { console.log("chalega?"); } // khaali string → skip if (null) { console.log("chalega?"); } // null → skip if (undefined) { console.log("?"); } // undefined → skip // Truthy examples — block CHALEGA if ("hello") { console.log("chala ✅"); } // non-empty string if (100) { console.log("chala ✅"); } // non-zero number if ("0") { console.log("bhi chala!"); } // "0" STRING hai → truthy! 😱
BOMB ALERT: "0" aur "false" — TRUTHY Hai!
  • "0" → yeh number nahi, ek non-empty STRING hai → truthy! Block chalega!
  • "false" → string hai, khaali nahi → truthy!
  • [] (khaali array) → truthy! 🤯 (JS mein arrays hamesha truthy, chahe khaali ho)
  • {} (khaali object) → truthy!
  • " " (sirf space) → non-empty string → truthy!

Yeh "0" wala trap interview mein 100% poocha jata hai!

Practical Use — Empty Check Pattern

Real code mein sabse common pattern — "value hai ya nahi?":

if (username) { ... } — username hai (non-empty) toh welcome, undefined/""/null hai toh login bhejo. if (!error) { ... } — koi error nahi hai toh aage badho. Short-circuit || wala fallback bhi isi pe based tha — Chapter 2 yaad hai na! 😉

🟡 Medium Task 4: Switch Calculator

a = 10, b = 3, op = "*" lo. switch se calculate karo: "+", "-", "*", "/" ke cases banao. Default mein "Galat operator" dikhao. Divide karte waqt zero se divide ka bhi dhyan rakho!

Idea: Har case mein break mat bhoolna! "/" case mein pehle check karo b !== 0 — nested condition ka use hoga.
let a = 10, b = 3, op = "*";

switch (op) {
  case "+": console.log(a + b); break;
  case "-": console.log(a - b); break;
  case "*": console.log(a * b); break;
  case "/":
    if (b !== 0) console.log(a / b);
    else console.log("Zero se divide nahi!");
    break;
  default: console.log("Galat operator!");
}
// 30

} else if (speed >= 40) {
  console.log("Smooth drive ✅");
} else {
  if (isHighway) {
    console.log("Highway pe itna slow? 🐢");
  } else {
    console.log("City traffic hai, theek hai 😌");
  }
}

Falsy Values (6)

  • false — obvious!
  • 0 aur -0 — zero paisa
  • "" — khaali string
  • null — khaali dabba
  • undefined — dabba hi nahi
  • NaN — galat maths
  • BAAKI SAB truthy — "0", "false", [], {}, " " bhi!

Common Mistakes

  • if (x = 5) — assignment ho gayi, === likho!
  • switch mein break bhoolna → fall-through
  • else-if ka order galat — strict condition pehle rakho
  • if (x == 5 or 6) — JS mein aisa nahi hota! x === 5 || x === 6 likhna padta hai
  • if (array) — khaali array bhi truthy hai!
  • if; — if ke baad semicolon = bug

Interview Facts

  • else-if mein pehla true hi chalta hai, baaki skip
  • switch internally === karta hai
  • Ternary expression hai — value return karti hai
  • default technically optional hai, par hamesha lagao
  • Short-circuit: user && user.isAdmin — safe check!
  • Fall-through se cases group kar sakte ho: case "Sat": case "Sun":
