Concept

DOM Kya Hota Hai? 🤔

Socho: tumhara TV — screen pe sab dikhta hai. Aur remote? Button dabao, channel badal jata hai, volume up/down. Tum TV ke andar haath nahi daalte — remote se bolte ho, TV khud badal jata hai. Web page bhi wahi TV hai, aur JavaScript tumhara remote! Par remote seedha TV se nahi bolta — wo ek control system se bolta hai. Us system ka naam: DOM — Document Object Model. Browser jab page kholta hai, toh har tag (heading, button, image) ko utha ke ek family tree bana leta hai — wahi DOM hai. JS tree se baat karta hai, tree page ko badal deta hai!

TV + Remote Analogy

Tum ne kabhi TV khol ke andar ki wires nahi chhedtе — remote se button dabate ho. Web page bhi waise hi hai: HTML file ek baar likhi gayi, par usko jeenda karne ka kaam DOM karta hai. JS boltа hai "is heading ka text badal do" — DOM turant kar deta hai, page reload ke bina! WhatsApp ka unread badge, Instagram ka like button, YouTube ka dark mode — sab DOM ka kamaal hai. Aur kamaal ki baat: tree ke har member ko JS se pakad sakte ho, badal sakte ho, naya paida kar sakte ho, aur hata bhi sakte ho. Chalo tree dekho! 🌳

Tool #2 — Select

Badalne se pehle pakadna zaroori hai — bina address keCourier parcel nahi milta, bina select kiye element nahi milta! Isliye bada element pakadne ke baad check karo: if (el) { ... } — safe player bano. Console mein error dekho toh pehle sawal: "kya maine null pakda?"

Tool #5 — Events

Page Ki Baat Sunno — Events Ka Jaadu 👂

Ab tak JS khud chal raha tha — page load hote hi sab ho gaya. Par asli app toh intezaar karta hai: "user ne button dabaya? Chalo phir kaam karte hai!" Yahi events hai — click, typing, form submit. addEventListener("click", function) boltа hai: "jab bhi click ho, mera function chalao." Aur yahan Ch5 ka callback wapas aata hai — full circle moment! 🔄

// HTML: <button id="btn">Dabao</button> <h2 id="title">...</h2> let btn = document.getElementById("btn"); btn.addEventListener("click", function() { document.getElementById("title").textContent = "Click Hua! 🎉"; }); // → function ABHI nahi chalega — CLICK hone pe chalega! // live typing pakadna — input event: document.getElementById("naamBox").addEventListener("input", function() { console.log("User ne likha: " + this.value); });
GOTCHA BOMB: btn ko Chalao Mat — Sirf Pass Karo! addEventListener("click", btn()) — bracket laga diye? Toh function abhi, turant chal gaya (page load pe hi!), aur addEventListener ko mila kya? function ka return value (undefined)! Click pe kuch nahi hoga. Rule Ch5 wala hi hai: function pass karo, chalao mat — btn ✅, btn() ❌. DOM ne bas recipe maangi thi, khana nahi!

Tool #6 — Create / Remove

Naye Elements Paida Karo — DOM Ka Nursery 🌱

Ab tak hum jo tha usko badal rahe the. Par chat ke naye messages, to-do ke naye items, cart mein naya product — ye toh pehle se the hi nahi! Inhe JS paida karta hai: createElement se banao, textContent se bharo, append se page pe utaro. Aur hatana ho toh remove() — bas, element gaya! 3-step recipe ek baar yaad, life bhar kaam.

// 3-step recipe — naya list item: let li = document.createElement("li"); // 1. BANAO (abhi page pe nahi hai!) li.textContent = "Doodh lena hai"; // 2. BHARO document.querySelector("#list").append(li); // 3. LAGAO // loop + createElement = poora list paida! for (let i = 1; i <= 3; i++) { let item = document.createElement("li"); item.textContent = "Item " + i; document.getElementById("list").append(item); } // udana bhi utna hi aasan: let pehla = document.querySelector("#list li"); pehla.remove(); // gaya! 💨
GOTCHA BOMB: Banaya Nahi Ki Aa Gaya! createElement("li") ke baad element page pe NAHI dikhta — wo abhi ek alag shelf pe bana hua hai, jaise parcel ban gaya par ghar pahucha nahi! append() bhool gaye toh element bina kaam ke paida hua — na dikhega, na chalega, bas memory mein padha rahega. Recipe ke teeno step zaroori hai: banao → bharo → lagao!
PRO TIP: append() har naye item ko list ke END pe lagata hai — jaise line ke peeche khada karna. Sabse aage chahiye (naya message upar)? prepend() use karo — WhatsApp ke naye messages upar aate hai na, wahi prepend hai! Aur poora list reset? list.innerHTML = "" — ek line mein sab gaya!

🟡 Medium Task 5: List Banao — Par Khaali Naam Nahi!

Input (id="itemBox"), button (id="addBtn"), list (id="myList"). Button click pe input ki value list mein naya li ban ke jaye. Par khaali input pe kuch na ho — warna khaali items ki bharmaar! (Ch3 ka if + DOM ki 3-step recipe)

Idea: 3-step: createElement("li") → textContent → append. Guard: if (value !== "") — ya aur smart: if (value) (khaali string = falsy, Ch3 yaad hai na!). Value nikalne ke liye itemBox.value.

});
🔴 Hard Task 6: Mini To-Do — Banao AND Udao

Task 5 ko upgrade karo: har naya li ke saath ek "✕" delete button bhi banao. Us pe click ho toh wahi li hata do. Poora cycle: add + remove — asli to-do app ka engine! (Tip: li ke andar button append karo, aur button ke listener mein this.parentNode = uska li!)

Idea: Delete button pe bhi addEventListener — andar this = button khud, this.parentNode = uska parent (li)! .remove() se hamesha ke liye gaya. Li ke andar do cheeze: text + button — dono append!
addBtn.addEventListener("click", function() {
  let value = itemBox.value;
  if (value === "") return;          // guard (early return!)

  let li = document.createElement("li");
  li.textContent = value;

  let del = document.createElement("button");
  del.textContent = " ✕";
  del.addEventListener("click", function() {
    this.parentNode.remove();        // button ka papa = li!
  });

  li.append(del);
  myList.append(li);
  itemBox.value = "";
});

Smart Counter

let count = 0;

  numEl.textContent = count;

plusBtn.addEventListener("click", function() {
  if (count < 10) {        // 10 pe lock!
    count++;
    show();
  }
});

minusBtn.addEventListener("click", function() {
  if (count > 0) {         // 0 se neeche nahi!
    count--;
    show();
  }
});

resetBtn.addEventListener("click", function() {
  count = 0;
  show();
});
